# 首次夹爪闭合前后的特征降维

使用已有400条原模型轨迹，不运行新仿真，不采集新特征。本轮仅分析首次闭合，不纳入抓持丢失事件。

## 样本与标签

首次闭合定义为夹爪命令首次由非正变正，不代表夹爪已经物理闭合或已经接触杯子。取该事件前最后一次推理，以及事件后第1、2、3次推理，共400、400、400、378点，总计1578点。每个时刻每条轨迹最多一个点；22条缺少第三次后续推理，不填充或复制特征。只有378条具有完整四时刻。

三种标签按轨迹定义，所有时刻沿用同一标签：

- 窗口内无新持续抓持、最终失败：174条。
- 窗口内有新持续抓持、最终失败：93条。
- 最终成功：133条，优先按最终成功归类。

窗口从首次闭合之后至第一次后续推理再往后90步；持续抓持要求检测连续为真至少5步，新抓持段的起点落在窗口内。它是仿真接触检测代理，不是人工确认的物理抓持；“窗口内无”不代表整条轨迹永远没有抓持。窗口统计包含下次推理前已经发生的抓持。

## 方法

分别使用1024维的腕部视觉均值、融合视觉均值和动作模块第24层全部动作token均值。特征按行L2归一化，每层所有时刻联合拟合t-SNE；没有PCA预降维。欧氏距离、perplexity=30、随机初始化、自动学习率、1500次迭代，随机种子0作为主图、种子1作为重复检查。没有使用结果标签拟合降维。

每行各时刻共享同一坐标系，但不同层独立拟合，不能比较跨层坐标方向、簇间距离和箭头长度。t-SNE是局部邻域展示，不是连续的物理状态空间。动作层特征还包含每次推理生成噪声的影响。

## 观察与定量检查

主图中成功样本在闭合后的视觉和动作特征中形成较集中的区域，两类失败样本则有较多混合。初始位置和当前抓持状态对照显示：这些分群与位置、接触状态及任务阶段相关，不能直接称为模型具有“失败意识”或已经实施有效纠偏。

为避免仅凭二维图判断，另在原始归一化高维特征中计算同一事件时刻的10近邻结果标签一致率。每个时刻每条轨迹只有一点，明确排除自身，因此不会把同一轨迹其他时刻当近邻。闭合后第一次推理的结果如下：

| 特征 | 高维近邻结果标签一致率 | 同一采样环内打乱标签的均值 |
|---|---:|---:|
| 腕部视觉 | 86.1% | 51.2% |
| 融合视觉 | 78.9% | 50.9% |
| 动作末层 | 81.3% | 51.3% |

环内打乱500次，随机种子195。这只控制粗粒度采样环，不控制连续位置、姿态、当前抓持、任务阶段等因素。它是样本内关联分析，不是留出集预测准确率。各时刻完整数值及未经多重比较校正的置换p值保存在summary.json中；不据此作因果结论。六次降维的10邻域trustworthiness为0.9951–0.9973；该指标不证明全局结构真实或纠偏有效，两个种子也不是全面超参数稳健性检验。

闭合后第三次推理只剩378条，因此该列不能直接与前三列作无选择偏差的成功比例比较。每30步推理一次，闭合到下一次推理可能延迟0–29步（最多1.45秒），各点不是夹爪接触瞬间的即时特征。
