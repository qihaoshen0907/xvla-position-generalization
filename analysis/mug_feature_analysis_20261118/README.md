# 首次推理内部特征：t-SNE为主，UMAP对照

完成400条轨迹首次推理的分析：133成功、267失败，每条轨迹1个点。6组特征×2种方法×3组参数×3个随机种子，共108个嵌入。未使用PCA。

输入是之前保存的均值池化1024维特征，逐向量L2归一化，使用欧氏距离；对单位向量，欧氏距离的近邻排序等价于余弦距离。每组特征分别拟合，不比较不同面板的坐标轴或簇间距离。未使用标签拟合嵌入。

主图参数在运行前固定为30、seed0。t-SNE perplexity=15/30/50，随机初始化、1500迭代；UMAP n_neighbors=15/30/50、min_dist=.1、随机初始化、500epochs；种子0/1/2。完整设置与版本见config.json。

## 主要观察

成功/失败在若干局部邻域有聚集，并非完全分离。位置着色显示这些结构同时与初始杯子位置相关。首次推理的机器人状态和语言匹配，标签是未来整条轨迹的结果，不是当前失败事件。

仅使用真实初始XY的10近邻，同结果邻居比例已达到88.3%，因此不能把内部特征的同结果聚集直接解释为独立的失败机制。这个量是描述性邻域统计，不是分类准确率，也不是留出测试成绩。

全部样本对的平均位置距离为8.40cm；特征近邻对应位置平均相距1.41–2.24cm。视觉到动作各阶段均保留与位置相关的结构，但这不证明位置被准确解码或被控制策略正确利用。

环内置换：固定每环成功/失败数，在每环内打乱标签1000次，保留原高维10近邻图。所有特征的观测同结果邻居比例高于环内置换均值，单侧经验p=1/1001（未作多重比较校正）。这仅排除“只有粗分环标签”的解释，未控制环内连续XY、遮挡或其他视觉变化，不作为因果证据。成对距离相关也仅作为描述统计，不把样本对当独立实验做显著性检验。

## 二维保真度与稳定性

| 特征 | t-SNE主图trustworthiness@10 | 高维10近邻保留率 | t-SNE不同种子近邻重叠范围（参数30） |

| vision_wrist_mean | 0.997 | 81.2% | 99.1%–99.4% |

| block_00_all_mean | 0.995 | 77.4% | 98.9%–99.3% |
| block_11_all_mean | 0.993 | 78.6% | 90.6%–91.9% |
| block_23_all_mean | 0.994 | 77.5% | 90.9%–92.1% |

trustworthiness高不等于二维保留所有信息；主图近邻保留率约68.5%–81.2%。主视角布局对随机种子更敏感，不能解读某个具体孤岛的形状。参数与种子扫描结果全部保留，未挑选分离最明显的图。
